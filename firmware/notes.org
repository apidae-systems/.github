#+title: Notes

| *Term*          | *🎨 Color*         | Abbreviation / Signal Name*            | *Bus Type*              | *Direction (ESP32 POV)*    | *Definition / Purpose*                                  |
|---------------+-------------------+----------------------------------------+-----------------------+--------------------------+-------------------------------------------------------|
| =*I²C *=        |                   | Inter-Integrated Circuit               |                       |                          | Two-wire serial bus for sensors and chips.            |
| =SDA=           | Blue              | Serial Data                            | I²C                   | ⇄ Bidirectional          | Carries data between master and slaves.               |
| =SCL=           | Yellow            | Serial Clock                           | I²C                   | → Output (master→slaves) | Provides timing for data bits.                        |
| =ADDR= / =SDO=    | Brown             | Address Select                         | I²C Sensors           | —                        | Chooses device I²C address (tie to GND or 3V3).       |
| =INT=           | Orange            | Interrupt                              | I²C / Sensors         | ← Input to ESP32         | Alert pin signaling “data ready” or “event”.          |
|               |                   |                                        |                       |                          |                                                       |
| =*SPI *=        |                   | Serial Peripheral Interface            |                       |                          | Four-wire high-speed bus for displays, SD cards, etc. |
| =SCK/CLK=       | Yellow            | Serial Clock / Clock Line              | SPI                   | → Output                 | Clock generated by master for sync.                   |
| =SO/MISO=       | Green             | Master In Slave Out                    | SPI                   | ← Input                  | Data returned from device to master.                  |
| =SI/MOSI=       | Blue              | Master Out Slave In                    | SPI                   | → Output                 | Data sent from master (ESP32) to device.              |
| =CS/SS=         | White             | Chip Select / Slave Select             | SPI                   | → Output                 | Chooses which device is active (LOW = selected).      |
| =DET=           | Purple            | Card Detect                            | SPI / SD              | ← Input (optional)       | Signals when SD card inserted.                        |
| =WP=            | Gray              | Write Protect                          | SPI / SD              | ← Input (optional)       | Indicates SD card lock switch state.                  |
|               |                   |                                        |                       |                          |                                                       |
| =*UART*=        |                   | Serial Text Link                       |                       |                          | Two-wire asynchronous serial communication.           |
| =TX=            | Orange            | Transmit                               | UART                  | → Output                 | Sends serial data to another device.                  |
| =RX=            | Green             | Receive                                | UART                  | ← Input                  | Receives serial data from another device.             |
|               |                   |                                        |                       |                          |                                                       |
| =*Display*=     |                   |                                        |                       |                          |                                                       |
| =VGA=           | Blue/Green/Red    | Video Graphics Array                   | Parallel RGB (Analog) | → Output                 | Sends analog RGB + sync signals to legacy monitors.   |
| =HDMI=          | Black             | High-Definition Multimedia Interface   | TMDS (Serial)         | → Output                 | Digital audio/video link for modern displays.         |
| =LVDS=          | Gray Twisted Pair | Low-Voltage Differential Signaling     | Differential Serial   | → Output                 | High-speed digital display link (used in laptops).    |
| =OLED=          | —                 | Organic Light Emitting Diode           | SPI / I²C             | → Output                 | Small low-power display panel for text/graphics.      |
| =TFT=           | —                 | Thin-Film Transistor (LCD type)        | SPI / Parallel        | → Output                 | Color LCD display used in dev boards.                 |
| =PWM=           | Yellow            | Pulse Width Modulation                 | GPIO (timed)          | → Output                 | Simulates analog voltage (e.g., LED dimming, motors). |
|               |                   |                                        |                       |                          |                                                       |
| =*Memory*=      |                   |                                        |                       |                          |                                                       |

| =FLASH=         | —                 | —                                      | SPI / QSPI            | ⇄                        | Non-volatile main storage for firmware.               |
| =SRAM=          | —                 | Static Random Access Memory            | Parallel              | ⇄                        | Fast temporary working memory.                        |
| =DIMM=          | Green             | Dual Inline Memory Module              | DDR / SDRAM           | ⇄                        | Removable RAM sticks (PCs).                           |
| =SD=            | —                 | Secure Digital                         | SPI / SDIO            | ⇄                        | Removable flash storage card.                         |
|               |                   |                                        |                       |                          |                                                       |
| =*Peripherals*= |                   |                                        |                       |                          |                                                       |
| =PCI=           | —                 | Peripheral Component Interconnect      | Parallel              | ⇄                        | Expansion bus for peripherals (legacy).               |

| =USB=           | White/Green       | Universal Serial Bus                   | Differential Serial   | ⇄                        | Connects peripherals, keyboards, storage, etc.        |
| =CAN=           | Gray Twisted Pair | Controller Area Network                | Differential          | ⇄                        | Robust automotive/industrial communication bus.       |
| =GPIO=          | —                 | General Purpose Input/Output           | —                     | ⇄                        | Simple programmable digital pin.                      |

| =Wi-Fi=         | —                 | —                                      | RF (2.4 / 5 GHz)      | ⇄                        | Wireless networking.                                  |
| =BLE=           | —                 | Bluetooth Low Energy                   | RF (2.4 GHz)          | ⇄                        | Short-range low-power radio link.                     |

| =BOOT=          | Blue              | Boot Mode                              | GPIO                  | ← Input                  | Selects firmware download mode.                       |
| =3V3= / =VCC=     | Red               | Power Supply                           | All                   | —                        | 3.3 V output from ESP32 to power sensors.             |
